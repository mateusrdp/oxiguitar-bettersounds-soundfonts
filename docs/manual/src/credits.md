# Credits

This project is mostly other people's work: the sounds are theirs, and we only point at them. Thank you, all of you, for recording these instruments and giving them away.

## The sounds

| Set | By | Licence |
| --- | --- | --- |
| Black and Green Guitars, Black and Blue Basses | [Karoryfer Samples](https://karoryfer.com/) | CC0 1.0 |
| Electric Guitar FSBS (clean, overdriven, distorted), the Spanish classical guitar, FSS Steel String Guitar | The [FreePats](https://freepats.zenvoid.org/) project | CC0 1.0; the steel-string guitar GPL-3.0-or-later with exception |
| Ukulele | Mateusz Dąbrowski, for FreePats | CC0 1.0 |
| MuldjordKit (the drums) | Lars Muldjord and the [DrumGizmo](https://drumgizmo.org/) team, SFZ by kinwie | CC BY 4.0 |

Wherever you publish a recording made with the drums, the licence asks for this credit: **Drum samples provided by DrumGizmo.org**.
